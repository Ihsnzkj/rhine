# Asset provenance

Binary assets under `frontend/public/` are generated by the scripts below,
drawn for this project, or come from sources with licences that permit
redistribution. With numpy 2.5, Pillow 12.3 and rsvg-convert 2.63 the
generators reproduce the committed files byte for byte; other versions may
differ in the last bits (resampling, compression) but not in content.

| file(s) in `frontend/public/` | origin |
|---|---|
| `scene/studio.hdr` | `gen_studio_hdr.py` — synthetic studio light probe |
| `scene/hex.png`, `scene/halftone.png`, `scene/card.png` | `gen_textures.py` (the card needs the logo: see below) |
| `scene/smoke.jpg` | `gen_smoke.py` — domain-warped fBm |
| `audio/draw.wav`, `access.wav`, `assemble.wav`, `process.wav`, `warning.wav`, `reveal.wav` | `gen_sfx.py` — synthesised |
| `audio/key1–3`, `erase`, `request`, `nav`, `open`, `close`, `choose`, `switch`, `toggle`, `arm`, `execute`, `error`, `glitch1–3`, `recover`, `standby`, `wake`, `blip1–2` (`.wav`) | Kenney *Interface Sounds*, CC0 1.0 — <https://kenney.nl/assets/interface-sounds>; renamed by role and converted to 48 kHz stereo WAV |
| `audio/bgm-loop.opus` | **not in the repository** — `tools/fetch-bgm.py` downloads "Rhine Lab.LLC" (© Hypergryph / Monster Siren Records) for personal use and cuts the loop |
| `fonts/Montserrat-*.ttf`, `fonts/JetBrainsMono-*.ttf` | SIL Open Font License 1.1, see `fonts/OFL-*.txt` |
| `dev/desktop.png` | a hand-drawn synthetic stand-in desktop (two empty windows, a clock) for the browser preview and the README recording — no real desktop content, metadata stripped |

The ∞ logo is a fan redrawing traced from frames of the official film; it is
built as SVG by `gen_logo.py` (and drawn procedurally in the frontend).

```sh
python3 tools/assets/gen_logo.py            # → tools/assets/build/logo-*.svg
rsvg-convert -w 300 tools/assets/build/logo-ink.svg -o tools/assets/build/logo300.png
python3 tools/assets/gen_textures.py tools/assets/build/logo300.png
python3 tools/assets/gen_studio_hdr.py
python3 tools/assets/gen_smoke.py
python3 tools/assets/gen_sfx.py
```
